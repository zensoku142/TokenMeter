# 今日分时日期控件设计与实现交接

## 1. 目标

在“今日分时”模式中，将当前日期选择控件调整为与 TokenSpider 面板一致的三段式日期控件，并重做展开日历的视觉样式。

本次只优化日期控件的结构、交互与视觉，不改变分时数据来源、保留期规则、图表渲染、统计口径、主题切换或面板布局。

## 4. 交互规范

### 4.1 未展开状态

控件总尺寸保持现有 `118 × 26` 逻辑像素，结构固定为：

```text
┌────┬──────────────┬────┐
│ ‹  │  2026-07-14  │  › │
└────┴──────────────┴────┘
```

- 左箭头：切换到前一天。
- 右箭头：切换到后一天。
- 中间日期文字：唯一用于打开日历弹层的区域。
- 点击左右箭头不得打开日历。
- 删除当前日历图标和下拉箭头。
- 日期文本使用动态值，格式固定为 `yyyy-MM-dd`，不得写死设计稿日期。
- 当选中日期等于保留期首日时，左箭头禁用。
- 当选中日期等于当前可选最大日期（通常为当天）时，右箭头禁用。
- 日期控件整体不可用时，三个分段均不可交互，并显示统一禁用态。
- 左右切换后继续走现有日期变更链路，刷新分时图、摘要、图例可用状态和提示信息。

### 4.2 展开状态

- 仅点击中间日期文字打开弹层。
- 弹层紧贴控件下方显示，不参与父布局，不推挤图表。
- 弹层需考虑屏幕边界；下方空间不足时可向上展开，但不得改变主面板尺寸。
- 点击可选日期后更新控件日期、刷新分时图并关闭弹层。
- 点击弹层外部或按 `Esc` 关闭弹层。
- 标题为动态单行结构：`‹ 2026年7月 ›`。
- 标题左右箭头仅用于切换月份；目标月份与可选日期范围无交集时禁用。
- 不保留原生月份、年份、翻月按钮三个大块。
- 周一为首列，星期标题为：`周一 周二 周三 周四 周五 周六 周日`。
- 周末不使用红色。
- 选中日期：圆角蓝底、白字。
- 当天未选中：蓝色细描边。
- 非本月日期和不可选日期：禁用色，不响应选择。
- 日期范围必须继续使用现有最小/最大日期逻辑，禁止选择未来或保留期外日期。

## 5. 视觉规范

### 5.1 通用

- 未展开控件：`118 × 26` 逻辑像素，不改变活动区标题行位置。
- 外框：`1px` 细边框、`6px` 圆角；三个区域之间使用细分隔线。
- 箭头区域保持紧凑，建议各约 `20px`，中间日期区域占剩余宽度。
- 字体沿用项目的 Microsoft YaHei UI 与现有 `11px` 控件层级。
- 弹层：单层边框、`8px` 圆角、轻量悬浮表面；禁止重阴影和多层卡片。
- 弹层宽度以七列日期完整、均匀显示为准，参考设计稿约 `288px`；不要为匹配生成图而扩大主面板。
- 所有颜色优先复用 `ThemeTokens`，不要新增一套独立主题常量。

### 5.2 浅色主题

- 表面：现有白色 `surface/elevated`。
- 文字：现有 `text/value/subtext`。
- 边框：现有 `border/border_hover`。
- 强调色：沿用 `#2076FA` 或当前主题的等价 accent。
- 禁用态：现有 `disabled`。

### 5.3 深色主题

- 表面：现有深色 `surface/elevated`，弹层可比主背景略抬升。
- 文字：现有 `text/value/subtext`。
- 边框：现有 `border/border_hover`。
- 强调色：沿用当前深色主题蓝色。
- 禁用态：现有 `disabled`。

## 6. 实现边界

### 必须保留

- “年度活动 / 今日分时”的原切换行为。
- 日期保留期配置及最小、最大可选日期。
- 分时历史读取、当前日刷新、图表数据与摘要文案。
- 刷新后保留用户已选历史日期；提供商变化时回到最新日期的现有行为。
- 浅色、深色、跟随系统主题切换。
- `640px` 最小宽度和 `820 × 550` 标准面板布局。
- 原有键盘焦点、工具提示和可访问名称；新增分段也需提供清晰的 accessible name/tooltip。

### 禁止扩展

- 不修改数据库结构、接口协议、配置协议或数据保留规则。
- 不新增第三方依赖。
- 不重构分时图、年度活动、数据层或主题系统。
- 不改变面板高度、活动区高度、图表坐标或图例布局。
- 不顺手修改版本、文案、命名、格式或无关文件。

## 7. 推荐的最小实现方向

这不是强制类名设计，但应保持小范围、可测试：

1. 将 `MinuteDateEdit` 调整为一个固定尺寸的复合控件，内部包含“前一天”“日期文字”“后一天”三个可交互区域。
2. 继续通过一个日期变更信号接入现有 `_on_minute_date_changed` / `_render_minute_date` 链路，避免复制业务逻辑。
3. 弹层可使用 `Qt.Popup` 容器承载紧凑标题和 `QCalendarWidget`；隐藏原生导航栏，设置周一为首列，并复用其日期范围、选择和键盘能力。
4. 月份标题和翻月按钮由弹层自己控制；月份切换不得突破日期范围。
5. 主题切换时只刷新现有 token/QSS 和必要图标，不重新创建数据状态。

如果现有 `QDateEdit` 无法在不引入脆弱事件拦截的情况下满足“只有日期文字打开弹层”，优先使用小型组合控件，不要依赖坐标猜测点击区域。
