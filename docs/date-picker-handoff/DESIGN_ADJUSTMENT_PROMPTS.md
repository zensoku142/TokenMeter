# 日期控件设计稿调整提示词

这些提示词用于后续只调整设计稿，不用于直接修改代码。每次应附带对应原始截图或当前设计稿，并明确只编辑日期控件区域。

## 通用约束前缀

```text
对所附 TokenSpider 产品截图进行精确局部编辑。严格保持原图画布、裁切、窗口框架、面板布局、文字、数据、图表、坐标、图例、按钮和分隔线不变，只允许修改“今日分时”右侧日期控件及其展开弹层。不得重排页面，不得改变图表数据，不得新增功能、说明、卡片或水印。

未展开控件保持现有 118×26 逻辑像素与总宽度，使用“左箭头 / yyyy-MM-dd / 右箭头”三段式。删除日历图标和下拉箭头。左、右箭头只表示逐日切换，只有中间日期文字表示打开日历。

展开弹层使用单层细边框、8px 圆角、轻量悬浮表面；顶部为紧凑单行“‹ 2026年7月 ›”，禁止使用月份、年份、翻月按钮三个大块。日历周一为首列，周末不使用红色。选中日期为圆角蓝底白字；今天未选中为蓝色描边；非本月和不可选日期为禁用色。
```
