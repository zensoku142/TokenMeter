# TokenMeter macOS 毛玻璃产品原型规范

## 1. 产品目标

TokenMeter 继续是一款轻量、常驻、可快速展开的 Windows 桌面用量监控工具。本次原型只改变视觉表达：让主面板与悬浮球具有现代 macOS 的半透明、层次、克制高光和精密控件感，同时保持用户现有操作习惯和全部功能。

核心体验不变：

```text
悬浮球快速读数
    ↓ 单击
展开完整面板
    ↓ Provider / 主题 / 刷新 / 设置
查看当前指标、趋势、活动与统计
```

### 设计稿解释规则

- 设计图尺寸 `1487 × 1058` 是展示画布，不是应用运行尺寸。
- 画布背景是透明材质演示，不是应用资产。
- 主面板与两个球同时出现是组件总览，不是运行态。
- 设计图中的日期、金额、Token 和百分比均为示例数据，实现必须使用实时数据。
- 图像生成可能造成细微文字、图表和比例误差；业务内容与布局边界以现有代码为真值。

## 4. 总体视觉语言

### 4.1 关键词

- 现代 macOS 材质感。
- 克制、轻量、安静。
- 半透明与背景折射。
- 清晰的数值层级。
- 低饱和蓝色强调。
- 极细边缘与内高光。
- 少量、柔和、自然的悬浮阴影。

### 4.2 禁止项

- 不使用赛博朋克霓虹。
- 不使用厚重多层阴影。
- 不使用拟物高光塑料感。
- 不使用大面积不透明卡片套卡片。
- 不新增侧边栏、搜索、导航、交通灯窗口按钮或功能入口。
- 不把桌面背景画进应用。
- 不依赖毛玻璃才能读取文字和数据。

## 5. 深色主题

### 5.1 材质

- 主窗体：烟熏蓝黑玻璃，桌面颜色可轻微渗透。
- Header 与内容连成统一材质，不做传统独立标题栏。
- 左侧指标区允许比主体稍密，强调主读数，但不形成厚重卡片。
- 边缘：上 / 左有极细冷白内高光，其余为低透明蓝灰边。
- 阴影：大范围、低透明、柔软，不形成黑色硬边。

### 5.2 建议色彩范围

以下为实现起点，不是必须逐像素照抄：

| 语义 | 建议 |
| --- | --- |
| 玻璃底 | `rgba(7, 18, 31, 0.78~0.88)` |
| 抬升玻璃 | `rgba(31, 48, 67, 0.55~0.72)` |
| 主文字 | `#F4F7FA` |
| 主数值 | `#FFFFFF` |
| 次文字 | `#AEB8C5` |
| 强调蓝 | `#3478F6` |
| hover 蓝 | `#5A93FA` |
| 成功色 | 沿用现有绿色语义 |

## 6. 浅色主题

### 6.1 材质

- 主窗体：乳白高透玻璃，不是纯白面板。
- 用户桌面的蓝、紫、暖色可以柔和折射，但不影响文字对比。
- Header、下拉框、主题切换和工具按钮使用同一套透明层级。
- 热力图空格必须仍清晰可见，不得因浅色玻璃而消失。
- 阴影比深色更轻，靠边缘高光和背景模糊体现层次。

### 6.2 字体要求

浅色主题使用已确认的“深色稿字体观感”：

- 主文字使用冷调近黑色，不使用中灰。
- 大数值紧凑、半粗、数字基线一致。
- 标题比标签明显，但不放大成宣传页面标题。
- 次级标签使用冷灰，保持可读对比。

### 6.3 建议色彩范围

| 语义 | 建议 |
| --- | --- |
| 玻璃底 | `rgba(244, 248, 255, 0.62~0.75)` |
| 抬升玻璃 | `rgba(255, 255, 255, 0.62~0.80)` |
| 主文字 | `#151A21` |
| 主数值 | `#0E1116` |
| 次文字 | `#56606D` |
| 强调蓝 | `#2F72E8` |
| hover 蓝 | `#1E61D2` |
| 成功色 | 沿用现有绿色语义 |

## 7. 字体系统

设计观感参考 SF Pro，但 Windows 实现不得依赖用户未安装的 Apple 字体，也不得新增字体依赖。

建议 Windows 安全字体栈：

```text
Segoe UI Variable → Segoe UI → Microsoft YaHei UI
```

实现时必须验证中文回退、数字宽度和 `640px` 下的截断。若全局字体变化影响设置窗口或现有布局，可只在主面板和悬浮球范围内应用。

| 层级 | 视觉要求 |
| --- | --- |
| 应用标题 | 紧凑半粗，保持现有识别度。 |
| 区域标题 | 半粗、低字距、明确但不抢主数值。 |
| Hero 数值 | 最大层级，半粗 / 粗体，优先使用表格数字。 |
| 次指标数值 | 统一基线与粗细，避免各卡片字号漂移。 |
| 标签 / 辅助信息 | 常规字重、冷灰色、清晰可读。 |
| 日期 / 金额 / 百分比 | 表格数字，避免刷新时宽度跳动。 |

## 8. Header 原型规范

Header 从左到右保持：

```text
应用图标 | TokenMeter | Provider 下拉框 | 峰谷提示（按需） | 弹性空间 |
浅/深主题 | 分隔 | 设置 | 刷新 | 收起
```

### 8.1 Provider Pop-up Button

这是本轮确认的重点组件。

| 属性 | 规范 |
| --- | --- |
| 尺寸 | 保持 `132 × 28px` |
| 圆角 | 约 `9~10px`，连续圆角，不做厚边框 |
| 文字 | 左对齐、垂直居中、紧凑中等字重 |
| 箭头 | 单个清晰 `chevron-down`，不得出现交叉、星形或粗 V |
| 默认态 | 与 Header 同色系但略抬升 |
| hover | 轻微提高亮度 / 对比，不改变尺寸 |
| focus / open | 使用克制蓝色边缘或内高光 |
| disabled | 降低文字和边缘对比，仍可识别当前值 |

弹层保持：

- 宽度 `132px`。
- 每行 `36px`。
- 最多显示 6 行。
- 继续在屏幕空间不足时向上展开并限制在工作区。
- 当前项使用柔和强调底和 check。
- hover 不得覆盖当前选中语义。
- 保留键盘导航、焦点、accessible name 和 tooltip。

### 8.2 主题与工具按钮

- 浅 / 深主题仍为二段式入口；跟随系统模式继续由当前主题控制器同步。
- 按钮约 `28~30px`，使用统一透明表面、圆角和边缘高光。
- active 使用低饱和蓝色填充，hover 只做轻微层级变化。
- 设置、刷新、收起的点击区域不得因视觉缩小。

## 9. 顶部指标与趋势

### 9.1 Codex

左侧固定语义：

1. 每周额度：`已用 N%`。
2. 剩余比例与重置倒计时。
3. 订阅套餐。
4. 套餐到期，只显示 `MM-DD`。

不在三张摘要卡中显示 `codex-extra-*` 专项额度。

右侧保持近 7 天 Token 柱状趋势。

### 9.2 DeepSeek / MiMo

左侧继续展示今日使用、余额、本月累计等当前 Provider 指标；右侧继续显示近 7 天金额趋势。不得把 Codex 的额度口径套用到 API Provider。

### 9.3 图表视觉

- 网格线细且低对比。
- 柱体使用从强调蓝到亮蓝的轻微渐变。
- hover、tooltip、坐标、日期和数据格式保持现有行为。
- 不为设计稿匹配而修改图表数据、数量、排序或坐标范围。

## 10. Token 活动

### 10.1 Codex 年度活动

- 保持月份、星期与热力格密度。
- 空格在浅色主题中用低透明冷灰，在深色主题中用抬升深灰。
- 活跃格沿用六级蓝色强度。
- tooltip、累计范围与统计口径不变。

### 10.2 API Provider 今日分时

- 保持“年度活动 / 今日分时”切换。
- 保持日期选择、分钟柱状图、图例、摘要、缩略范围条。
- 视觉主题化不得改变图例开关、日期边界、数据筛选或估算说明。
- Codex 模式继续隐藏分时切换入口。

## 11. 使用统计与状态栏

- 保持五列统计结构和竖向分隔。
- 数值使用统一粗细、基线和表格数字。
- 状态栏左侧语义点继续区分更新、成功、警告和错误。
- 右侧最后更新时间继续动态显示。
- 不新增装饰性卡片或多余统计。

## 12. 悬浮球原型

### 12.1 共同外观

- 透明圆形玻璃壳。
- 极细蓝色边缘与柔和外环。
- 顶部轻微内高光。
- 背景颜色可折射，但文字始终清晰。
- 深浅主题只改变玻璃、文字、边缘与阴影，不改变数据。

### 12.2 Codex 百分比球

- 中心显示剩余百分比。
- 继续使用真实百分比控制现有液面高度和波动动画。
- 设计稿中的外环可以作为辅助进度与材质高光，但不得与中心百分比含义冲突。
- 未知值、0%、100% 和长重置文案必须安全显示。

### 12.3 金额球

- 上半区：今日使用金额。
- 下半区：余额。
- 保持现有标签和值的更新逻辑。
- 长金额继续使用当前字号降级规则，避免溢出。

### 12.4 交互状态

| 状态 | 行为与视觉 |
| --- | --- |
| default | 正常玻璃、边缘和数据。 |
| hover | 光晕与边缘轻微增强，光标仍为可拖动。 |
| pressed / drag | 保持按下反馈与 ClosedHandCursor。 |
| click | 未超过拖动阈值时展开面板。 |
| peak | 保留琥珀色峰值提醒，不改语义。 |
| edge hidden | 保持现有触发条、恢复和动画。 |

## 13. 状态覆盖矩阵

原型实现至少覆盖：

| 维度 | 状态 |
| --- | --- |
| 主题 | light、dark、system→light、system→dark |
| Provider | DeepSeek、MiMo、Codex |
| 面板 | compact、expanded、annual、minute |
| 请求 | loading、refreshing、ok、partial、error、stale |
| Provider 下拉 | default、hover、focus、open、selected、disabled |
| 悬浮球 | quota、money、unknown、0%、hover、pressed、peak |
| 窗口 | 正常、拖动、失焦、设置子窗口、边缘吸附、多屏、高 DPI |

## 14. 可访问性与可用性

- 不用颜色作为唯一状态提示。
- 文字对比必须在实际桌面背景下验证。
- Provider、主题、设置、刷新、收起保持 accessible name 和 tooltip。
- 焦点态在深浅主题都可见，但不得成为刺眼粗蓝框。
- 点击区域尺寸不得因图标变细而缩小。
- 原生模糊关闭或失败时，文字、热力图和图表仍须满足可读性。

## 15. 原型验收

- [ ] 深浅主题都具有可识别的玻璃层级，不是简单透明色块。
- [ ] 浅色主题使用深色稿的字体层级与数值观感。
- [ ] Provider 下拉框与工具栏形成统一 macOS Pop-up Button 风格。
- [ ] 下拉框箭头是单个清晰的向下 chevron。
- [ ] 现有窗口尺寸、区域顺序和信息密度不变。
- [ ] 设计稿背景未被加入应用。
- [ ] 展开面板时悬浮球仍隐藏。
- [ ] Codex、DeepSeek、MiMo 内容与统计口径保持各自语义。
- [ ] 分时、日期、图例、刷新、设置、主题、拖拽和边缘隐藏功能不变。
- [ ] 原生材质不可用时有安全降级视觉。
- [ ] 深浅主题在 `640px`、`820px`、125% / 150% DPI 下无截断。
