更新类型：功能新增、Bug 修复、功能优化与文档更新（首个正式版）

这是 TokenMeter 独立桌宠扩展的首个正式版，包含 `pet-v0.1.0-beta.1` 的全部能力及后续更新，不替代主程序 Latest。建议配合 [主程序 v1.14.0](https://github.com/zensoku142/TokenMeter/releases/tag/v1.14.0) 使用；最低兼容主程序 `1.14.0-beta.1`，平台为 Windows x64，通信协议保持 `1`。

### 新增

- 集成 VPet 默认角色与核心互动，支持触摸头部和身体、拖动、提起、缩放、左右贴边、自主移动与待机动作；右键可打开原用量面板、设置、暂停自主活动、返回悬浮球或退出。
- 额度云朵气泡以百分比和缓慢变化的液体水位展示订阅剩余额度，余额账户显示金额；同步当前主题和 DeepSeek 峰谷提示色，空闲后淡化，双击打开面板，单击不抢焦点。
- 气泡可选择贴边自动、悬停、随机、悬停＋随机四种展示模式；随机间隔为 3–5、5–10 或 10–20 分钟，每次显示真实额度 8 秒，悬停可延长，手动开关优先。
- 新增独立的喝水与休息提醒，默认关闭，可选择提醒间隔；使用原有文字对话框，同时到期时合并显示，不发声音或系统通知。偏好自动保存在 `vpet/layout.json`。
- 补齐完整待机动作，包括自娱自乐、侧身互动、无聊、吹泡泡、比心、喵喵、探看、下蹲、网球、哈欠及坐下/躺下序列；每轮随机遍历动作与状态版本，支持只有循环段的动画入口。

### 修复与优化

- 修复主程序启用桌宠后仍出现在 Windows Alt+Tab 窗口切换列表的问题；桌宠与额度气泡不占独立任务栏或切换项，保留触摸、拖动、右键菜单与打开主面板的交互。独立开发演示仍保留窗口入口。
- 提醒优先于自主活动，显示期间暂停走动；贴边时暂时移入屏幕，结束后归位，用户拖动或缩放后不强制归位。隐藏或休眠后重新计时，不补发积压提醒；关闭自主活动不影响提醒。
- 随机额度、喝水和休息提示统一使用原有常规姿态，不播放轻拍动作或新增素材。拖动、缩放、菜单、隐藏和退出会取消旧自主序列及回调，避免动作冲突。
- 贴边后可自行回到屏幕内继续活动；缩窄拖放吸附范围，默认大小约为 5 像素，可停在墙边而不直接隐藏，靠墙时优先选择符合原核心边界条件的爬墙动作。
- 处理不同缩放、屏幕边界和负坐标显示器下的拖动、贴边与气泡定位；气泡手动显隐选择在当前状态内保持，隐藏时停止波浪动画。
- 修复动画缓存清理的时区偏差，限制并发解码并逐帧释放原始图片，降低加载时的内存峰值；核心源码随仓库维护，动画仍固定到既有上游提交。
- 不包含底部工具栏、投喂、睡眠、工作、学习、游戏、金币、经验、等级或其他养成玩法，也不包含 Steam、联机、创意工坊、照片图库或额外代码插件。
- 内置 .NET 8 运行时，无需另外安装；仅通过本机父子进程管道接收展示字段，不读取账户凭据，主程序退出时同步关闭宿主。

### 安装、兼容与校验

- 先安装主程序 `v1.14.0`，通过“设置 → 桌宠”下载后手动启用；体验版扩展用户可点击“检查桌宠更新”单独升级，不需要手动解压到安装目录。
- 附件：`TokenMeter-Pet-v0.1.0-x64.zip`、`extension.json`、`SHA256SUMS.txt`。校验文件覆盖 ZIP 与版本清单；SHA256 不等同于独立发布签名。
- 通信协议和最低兼容主程序版本未变，已有 `v1.14.0-beta.1` 主程序仍可使用本扩展；稳定主程序只选择稳定扩展。
- 桌宠原生菜单目前为中文。关闭或卸载后恢复原悬浮球，保留账户、用量、主题及桌宠偏好，不影响主程序日常使用。
