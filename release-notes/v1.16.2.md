更新类型：Bug 修复与功能优化（修订版）

本版本汇总 `v1.16.1` 之后的桌宠设置、更新和实例管理调整，替代主程序 Latest。配套桌宠为 [`pet-v0.2.2`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.2)，主程序与桌宠仍独立下载和更新。

### 修复与优化

- 桌宠更新保留在“设置 → 桌宠”，改为独立选择正式版或体验版；检查当前通道的最新兼容版本，不再提供无法降级的历史版本选择。手动与自动更新使用一致的确认提示，切换通道后丢弃旧请求结果。
- 角色按缩略图与名称逐行展示，安装、卸载和设为默认按钮紧跟角色名称，收紧角色及更新区布局；默认 VPet 角色显示其名字“萝莉斯”。
- 移除预设额外实例数量，改为启动后从桌宠右键菜单即时增加萝莉斯或鲸鱼娘，并可单独关闭任意实例。关闭最后一只后恢复悬浮球；旧数量配置不再自动拉起额外窗口。
- 保留每个实例独立的位置、缓存和用量来源；扩展更新、卸载和主程序退出时仍统一停止实例。

### 验证

- 本地全量 Python 回归 1685 项通过、4 项跳过，另有 172 项子测试通过；Ruff 与 Python 依赖审计通过。真实素材转码检查确认动作首帧与站立素材的人物轮廓和脚底基线一致。
- WPF 宿主 Release 编译和桌宠运行自检通过。GitHub Actions 再次执行全量测试、依赖审计、主安装器构建、启动及覆盖安装验证。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.16.2-x64.exe`、`SHA256SUMS.txt`。覆盖安装保留账户、用量、主题及桌宠配置。
- 右键新增与单独关闭实例需要主程序 `1.16.2` 和桌宠 `0.2.2` 配合使用。桌宠 `0.2.2` 的最低兼容主程序提高到 `1.16.2`，避免旧主程序展示无法响应的新菜单；旧桌宠仍可继续使用。
- 主安装器不包含角色动画；SHA256 用于完整性校验，不等同于独立发布签名。
- 完整差异：[v1.16.1 → v1.16.2](https://github.com/zensoku142/TokenMeter/compare/v1.16.1...v1.16.2)。
