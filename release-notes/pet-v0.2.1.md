更新类型：功能新增、Bug 修复与功能优化（修订版）

本版本汇总 `pet-v0.2.0` 之后的角色资源和交互改进，不占用主程序 Latest。建议配合主程序 [`v1.16.1`](https://github.com/zensoku142/TokenMeter/releases/tag/v1.16.1) 使用分角色下载与多开；最低兼容主程序仍为 `1.14.0-beta.1`，平台 Windows x64，通信协议保持 `1`。

### 新增

- 除兼容旧客户端的完整包、宿主更新包外，增加 VPet 默认角色和鲸鱼娘的独立 ZIP。新主程序首次只下载所选角色，之后可单独添加或删除另一角色；已安装资源在合并前校验，失败时保留原包。
- 宿主支持多个独立进程与固定角色实例，各自保存位置和缓存；右键角色菜单只显示当前包中实际安装的角色。
- 每个桌宠实例的右键“显示来源”可独立选择平台或账户档案；宿主只接收显示名称与临时选项编号，账户档案 ID 和凭据不通过桌宠通信管道。
- 悬停桌宠时按住 Ctrl 滚动鼠标滚轮即可调整大小。每档沿用右键菜单的 20 单位步长和 160–320 的尺寸范围；普通滚轮与拖动行为不变。

### 优化

- VPet 多帧动画在构建时预缩至宿主实际使用的 250 像素；单帧图片保留原尺寸和放大清晰度，动画文件名及帧时长不变。
- 鲸鱼娘的 106 个动作继续以预转码 APNG 随包提供，仅保留一个 WebM 样本用于自定义动画检查，减少重复素材。自定义 WebM 仍需用户自行提供 FFmpeg。

### 验证

- 本地全量 Python 回归 1685 项通过、4 项跳过，另有 172 项子测试通过；角色包下载、合并、删除、更新回滚、多实例生命周期和独立显示来源测试通过。
- WPF 宿主 Release 构建通过，0 警告、0 错误；GitHub Actions 将再次执行扩展打包、测试及附件校验。完整发布包的实际体积以本次构建附件为准。

### 安装、兼容与校验

- 附件：`TokenMeter-Pet-v0.2.1-x64.zip`、`TokenMeter-Pet-Host-v0.2.1-x64.zip`、`TokenMeter-Pet-vup-v0.2.1-x64.zip`、`TokenMeter-Pet-whale-v0.2.1-x64.zip`、`extension.json`、`SHA256SUMS.txt`。校验文件覆盖全部 ZIP 与清单；SHA256 不等同于独立发布签名。
- 主程序 `1.16.1` 可管理单个角色和多开；旧主程序继续使用完整 ZIP。升级或删除角色时保留桌宠位置偏好、账户、用量和主题。此桌宠 Release 不占用仓库 Latest。
