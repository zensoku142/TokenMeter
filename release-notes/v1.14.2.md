### 从旧版本直接升级

可直接覆盖安装本版本，无需逐个安装中间版本。`v1.14.1` 及更早客户端仍只显示目标 Release 正文，因此在这里补充跨版本升级的重要变化：

- 从 `v1.14.0` 或更早版本升级：包含 `v1.14.1` 的桌宠自动更新提醒。“启动后自动检查”也会检查已安装的桌宠，确认后进入桌宠页更新；主程序更新优先完成，重启后继续检查桌宠。未安装桌宠时不自动下载。
- 从 `v1.13.2` 或更早版本升级：包含 `v1.14.0` 的可选 VPet 桌宠与独立扩展管理，以及配套桌宠的额度气泡、生活提醒和自主活动；主安装包仍不捆绑桌宠资源。
- `v1.14.0` 按账号隔离用量、账单和分时历史，修复凭据清除、历史费用、Codex 日志统计和热力图分档问题，并加强更新校验。旧历史首次升级时归入当前账号，建议升级前备份数据目录并确认当前登录账号。
- 自定义接口需要有效的 HTTPS；原有 HTTP 地址需要调整。源码用户如使用已移除的旧兼容导入入口，需按项目结构说明调整。另包含主题主色同步、水球动画、历史采集性能及安装包 ICU DLL 修复。

中间版本的完整说明：[v1.14.1](https://github.com/zensoku142/TokenMeter/releases/tag/v1.14.1)、[v1.14.0](https://github.com/zensoku142/TokenMeter/releases/tag/v1.14.0)。已经使用 `v1.14.1` 的用户可直接查看下文本次变更。
