更新类型：Bug 修复与功能优化

本版本集中修正轻底细环交互、账户数据归属和本机分时统计，并优化设置窗口与桌宠提醒。配套桌宠优化以独立扩展 `pet-v0.3.2` 发布。

### 修复

- 修复细环纵向拖动容易误触排序的问题：直接拖动图标或留白移动窗口，长按图标后上下拖动排序，并补充多语言提示。
- 修复主题色和圆环颜色选择窗口可能被置顶面板遮挡的问题；保留确认、取消及自定义颜色保存行为。
- 修复 MiMo 浏览器回退可能读取其他登录账户数据的问题；无法确认相同账户时要求重新认证。
- 修复 Codex 部分日志或目录读取失败时，不完整分时统计覆盖已保存记录的问题；读取恢复后继续更新，正常删除日志仍会同步清除。
- 修复关闭或隐藏本机统计窗口后，迟到的图表悬停回调访问已释放控件的问题。
- 修复桌宠低额度提示未遵守自定义阈值和静默时段的问题。

### 优化

- 多账户默认关闭，未主动开启时不采集账户档案或自动连接 CC Switch；保留已明确保存的开关选择和账户配置。
- 相同分时统计快照不再重复改写数据库，继续执行过期清理，并保留事务失败后的重试与数据恢复能力。
- 配套桌宠扩展支持各角色独立记忆尺寸，并优先准备启动和交互动画，其余动作后台预热或按需加载。
- 整理五种语言的 README 产品介绍、截图位置及操作说明；合入开发依赖维护更新。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.17.1-x64.exe`、`SHA256SUMS.txt`；覆盖安装保留用户数据。
- 配套桌宠为 `pet-v0.3.2`，最低兼容主程序仍为 `1.17.0`，通信协议保持 `1`；主安装包不含角色动画，需独立安装或更新桌宠扩展。
- SHA256 用于完整性校验，不等同于独立发布签名。
