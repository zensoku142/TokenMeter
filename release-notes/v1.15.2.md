更新类型：Bug 修复、功能优化

本次发布恢复 DeepSeek 平台改版后的余额、用量与费用采集，完善平台 Token 获取和续签后的历史归属；同时优化设置页主动打开浏览器或外部资料时的交互，并新增周额度环方向开关。现有账号配置、用量数据库、桌宠扩展和安装升级方式保持兼容。

### 修复

- 适配 DeepSeek 新版按 API Key 用量与费用接口，按本地时区请求月份范围，并保留旧接口作为兼容回退。
- 修复 DeepSeek 返回业务错误码时被误报为“返回结构已变化”的问题；无效或过期的平台 Token 现在会显示明确提示。
- 修复一键获取仅保存 Cookie、无法满足新版接口认证的问题；现在会捕获并验证平台 Token，同时兼容原始 Token、完整 Bearer 值和浏览器本地存储 JSON。
- 修复 DeepSeek 平台 Token 续签后被误识别为新账号、导致既有分时历史暂时不可见的问题；同账号历史会在严格匹配每日汇总后无损归并，不同账号继续隔离。
- 修复 DeepSeek 新版账户摘要缺少旧月度字段时，界面可能把未知值显示为零的问题。
- 修复设置页点击“一键获取平台 Token”“查看国务院通知”、供应商官方用量页或项目主页后，面板因浏览器抢占焦点而自动关闭的问题。
- 修复不同界面语言下“查看国务院通知”未打开对应语言页面的问题。

### 优化

- 新增周额度环方向开关，可在设置中选择顺时针或逆时针绘制，并自动保存选择。
- 设置页主动发起外部跳转时保持原页面打开；用户返回应用后自动恢复普通失焦收起规则。
- DeepSeek 请求头统一补全网页客户端标识，并兼容复制整行 `Authorization` 的输入方式。

### 验证

- 完整回归：1658 项测试、172 项子测试通过；4 项按环境跳过。唯一 ZIP 重名警告来自恶意扩展包测试，符合预期。
- Ruff 检查、DeepSeek 新旧响应归一化、Token 捕获验证、历史续签归并和设置页外部跳转交互测试通过。
- 使用现有 `usage.db` 的临时副本验证续签迁移，确认原有 Token 与费用分时记录可以恢复到当前账号作用域，正式数据库更新前已保留自动备份。
- 发布前由 GitHub Actions 继续执行完整测试、依赖审计、安装包构建、首次安装、覆盖安装与启动自检。
