更新类型：功能新增

本版本新增 OpenAI API 组织美元可用余额，可与 Codex 订阅额度分别查看。

### 新增

- 在“设置 → 账户连接”选择 OpenAI API，通过专用浏览器登录并选择组织。完成连接后，可在主面板、多平台总览和轻底细环查看该组织的可用余额。
- API 余额以美元显示，细环使用 API 角标区分 Codex 订阅额度。连接失效时提示重新连接，已有成功快照标明未更新。

### 验证

- 本地已通过 OpenAI API 余额、账户连接、刷新、界面及细环相关回归，覆盖组织切换、登录失效和缓存状态。
- 发布流水线运行全量测试、依赖审计、安装器构建、覆盖安装和启动自检，并生成校验文件。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.17.2-x64.exe`、`SHA256SUMS.txt`；覆盖安装保留用户数据。
- 可选桌宠扩展仍为 `pet-v0.3.2`，通信协议为 `1`。
- SHA256 用于完整性校验，不等同于独立发布签名。
- 完整差异：[v1.17.1 → v1.17.2](https://github.com/zensoku142/TokenMeter/compare/v1.17.1...v1.17.2)。
