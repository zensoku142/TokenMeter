更新类型：功能新增、Bug 修复与功能优化（正式版）

本版本汇总 `v1.15.2` 之后的桌宠入口与更新体验，替代主程序 Latest。配套桌宠扩展为 [`pet-v0.2.0`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.0)；主程序与桌宠分别安装和更新。

### 新增

- 在“设置 → 桌宠”中可先选择带缩略图的 VPet 默认角色或鲸鱼娘，再启动桌宠；未安装扩展时也可预选。选择与桌宠右键菜单共用现有角色偏好，重启后保留。
- 检查桌宠更新后可查看兼容版本列表，选择具体版本安装或升级；旧版本可查看，仍遵守禁止降级规则。后台自动检查继续只提示最新版本。
- 配套桌宠扩展新增鲸鱼娘真实动画、额度气泡样式和余额／额度反馈，详见独立桌宠正式版说明。

### 修复与优化

- 只有角色选择字段的旧式桌宠布局仍使用默认位置和尺寸，启动时直接加载已选角色。
- 桌宠资源和动画仍通过独立扩展交付，未安装桌宠时原有悬浮球及用量面板继续可用。

### 验证

- 本地全量回归：1665 项通过、4 项跳过，另有 172 项子测试通过；主程序 onedir 构建与启动冒烟检查通过。
- GitHub Actions 将再次执行全量测试、构建和安装覆盖验证；实际账户采集及多显示器环境仍欢迎反馈。

### 安装、兼容与校验

- 附件为 `TokenMeter-Setup-v1.16.0-x64.exe` 和 `SHA256SUMS.txt`；安装主程序后，在“设置 → 桌宠”下载并启用配套扩展。
- 桌宠通信协议仍为 `1`。正式版主程序自动检查稳定桌宠版本；手动版本列表显示兼容的可安装版本。
- 校验文件覆盖安装包；SHA256 不等同于独立发布签名。本版本成为新的主程序 Latest。
