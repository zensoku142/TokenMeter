更新类型：功能新增、优化与兼容性调整

本版本新增轻底细环、CC Switch Codex 多账号额度采集和公开重置动态，并调整支持的平台范围。桌宠扩展独立发布，配套桌宠为 pet-v0.3.0。

### 新增

- 新增轻底细环，支持多平台、多账号展示、拖动排序、贴边吸附和颜色设置。
- 支持发现 CC Switch 托管的 Codex OAuth 账号，后台采集并在多账户、细环和桌宠间共享缓存；桥接依赖 CC Switch 内部命令，版本变化可能需要适配。
- 细环悬停详情增加 Codex 社区公开重置动态及可选提醒；公开信息不代表个人额度到账。

### 优化与修复

- 改进大凭据保存、账户配置、Codex 用量解析和桌宠扩展管理。
- 更新官网、截图和多语言说明；改进桌宠动画缓存及鲸鱼娘交互。小龙娘通过独立桌宠扩展提供。
- 修正发布构建的素材来源：小龙娘动画直接使用本仓库的文件。
- 修复速度图图例和主题颜色，以及更新窗口被置顶窗口遮挡的问题。

### 平台兼容性

- 主界面保留 Codex、Claude Code、Cursor、DeepSeek、MiMo 和 NayutoAI 六个平台入口；本版本移除 OpenRouter、Moonshot、GitHub Copilot、GLM / Z.ai、Kimi Coding、MiniMax、ElevenLabs、Gemini CLI 和 Antigravity 入口。依赖这些平台的用户升级前请留意。

### 验证

- Windows 本地针对性测试 218 项通过、1 项跳过；桌宠宿主 Release 编译通过，0 警告、0 错误。

- 发布流水线将执行全量测试、依赖审计、安装器构建、覆盖安装与启动自检。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.17.0-x64.exe`、`SHA256SUMS.txt`；覆盖安装保留用户数据。
- 配套桌宠为 `pet-v0.3.0`；主安装包不含角色动画，需另行安装桌宠扩展。
- SHA256 用于完整性校验，不等同于独立发布签名。
- 完整差异：[v1.16.7 → v1.17.0](https://github.com/zensoku142/TokenMeter/compare/v1.16.7...v1.17.0)。
