更新类型：功能新增

本版本重新上线 WorkBuddy 平台，面板改为积分口径，并新增按模型查看积分消耗。

### 新增

- 恢复 WorkBuddy 平台接入：在“设置 → 账户连接 → WorkBuddy”通过专用浏览器登录，主面板展示剩余积分、套餐基础 / 赠送 / 购买与平台奖励积分，以及本月每日积分图和额度明细。
- 主面板新增“模型积分消耗”栏，与每日积分图左右并列：按积分降序显示模型名、消耗积分与占比，可切换“本月 / 今日”，模型较多时仅列表内部滚动，标题和时段切换保持固定。
- 积分活动区支持本月汇总与额度明细查看，占比按所选时段的全部模型积分计算。
- 悬浮球支持积分平台，以积分值和说明代替金额显示。

### 修复

- 专用浏览器采集成功后先保存凭据再更新界面草稿，避免切换设置标签页时用旧草稿覆盖刚保存的连接。
- 使用明细统计失败时单独上报，不再连带影响已成功的额度与余额显示。
- 点击 OpenAI API 余额细环时，仅在已配置并启用 Codex 的情况下打开 Codex 用量面板，其余情况下保持当前界面。

### 优化

- 轻底细环的数值按可用宽度分级显示，大额余额不再被截断或显示成 0。
- OpenAI API 细环的 `API` 标记移至圆环下缘，文字颜色随浅色和深色主题切换。
- 本月积分图的日期刻度按可用宽度自动疏化，窄窗口下仍保留今天与月末。

### 验证

- 本地已完成 WorkBuddy 面板、模型积分消耗、额度明细、细环、账户连接与多平台切换的回归测试，覆盖今日 / 本月切换、零消耗模型、明细为空、缓存跨日跨月、缓存不可用与切换账号等状态。
- 已在真实账号上核对：模型积分合计与“本月消耗积分”“今日消耗积分”逐项一致，日期与调用次数吻合。
- 本地已验证 OpenAI API 细环在浅色与深色主题、40px 与 58px 宽度下的显示，以及 Codex 已配置、未配置和已禁用时的点击行为。
- 发布流水线运行全量测试、依赖审计、安装器构建、覆盖安装和启动自检，并生成校验文件。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.17.3-x64.exe`、`SHA256SUMS.txt`；覆盖安装保留用户数据。
- WorkBuddy 此前处于下线状态，本版本重新提供；已保存的旧凭据继续兼容读取，不会被清空。
- 可选桌宠扩展仍为 `pet-v0.3.2`，通信协议为 `1`。
- SHA256 用于完整性校验，不等同于独立发布签名。
- 完整差异：[v1.17.2 → v1.17.3](https://github.com/zensoku142/TokenMeter/compare/v1.17.2...v1.17.3)。
