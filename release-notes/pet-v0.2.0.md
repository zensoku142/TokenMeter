更新类型：功能新增、Bug 修复与功能优化

本版本让桌宠宿主支持独立人物资源包，并加入完整动作验证入口。通信协议仍为 `1`，最低兼容主程序仍为 `1.14.0-beta.1`。

### 新增

- 支持通过受控 `--resources-dir` 加载已安装人物形象；目录缺失时自动回退包内默认角色。
- 新增开发者动作面板，覆盖 Default、StartUP、16 个 Move、Raised、Touch、Say、SideHide、State 与 IDEL 动作。
- 新增 318 段、2488 帧的动作合同及分层角色确定性渲染工具。

### 修复与优化

- PNG 帧按文件名稳定排序，避免不同文件系统枚举顺序造成错帧。
- 动画缓存键加入帧名、大小与高精度写入时间指纹，同路径替换人物图片后不再复用旧缓存。
- 动作面板播放期间暂停自主动作和生活提醒，结束后恢复默认姿态。

### 验证

- .NET Release 构建通过，0 个编译错误。
- 真实宿主加载 318 个动画段；动作面板必需类型、16 个 Move 名称、IDEL、Say 与状态序列检查通过。
- 桌宠扩展、打包、配置、动作合同及 PNG 运行时相关回归测试通过。

### 安装、兼容与校验

- 附件包含完整桌宠包、轻量宿主更新包、`extension.json` 与 `SHA256SUMS.txt`。
- `pet-v0.1.2` 可直接升级；旧主程序仍可使用内置角色，人物形象管理需主程序 `1.15.0`。
- 完整差异：[pet-v0.1.2 → pet-v0.2.0](https://github.com/zensoku142/TokenMeter/compare/pet-v0.1.2...pet-v0.2.0)。
