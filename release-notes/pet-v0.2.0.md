更新类型：功能新增、Bug 修复与功能优化（正式版）

本版本汇总 `pet-v0.1.4` 之后的桌宠变更，替代此前的桌宠稳定版，但不占用主程序 Latest。建议配合主程序 [`v1.16.0`](https://github.com/zensoku142/TokenMeter/releases/tag/v1.16.0) 使用；最低兼容主程序 `1.14.0-beta.1`，平台 Windows x64，通信协议仍为 `1`。

### 新增

- 新增独立角色“鲸鱼娘”，保留 106 段透明 WebM，并在构建时转换为可实际播放的 APNG。支持待机、自主活动、点击、拖拽、甩抛和动作菜单；原 VPet 角色继续可用。
- 可在右键菜单切换角色，偏好保存在现有布局文件中。新主程序支持在桌宠设置页通过缩略图预选启动角色，并从兼容版本列表中选择安装版本。
- 额度气泡可选“对白框”或“简洁卡片”；鲸鱼娘在屏幕下角显示余额或额度卡片，DeepSeek 余额展示峰谷及扣费反馈，额度下降时显示减少值。

### 修复与优化

- 调整默认角色贴图、拖拽边界、气泡和卡片布局；缩窄百分比额度卡片，并修复金额与峰谷标记的间距。
- 全部内置鲸鱼娘动作在构建阶段转码，发布包不含 FFmpeg 可执行文件，首次点播不需要用户安装转换器。自定义 WebM 覆盖仍受支持，但需要用户自行安装 FFmpeg 并加入 `PATH`。

### 验证

- 本地全量 Python 回归 1665 项通过、4 项跳过，另有 172 项子测试通过；桌宠宿主编译与 106 段动作资源转换完成。
- 真实 WPF 宿主桌面自检 289 项通过；完整 ZIP 与宿主 ZIP 完整性、2730 个资源文件、106 段 APNG、清单和三个 SHA256 校验通过，包内无 FFmpeg 可执行文件。GitHub Actions 将再次执行安装、更新及打包测试。

### 已知限制

- 鲸鱼娘卡片使用主程序当前活动平台的用量消息，尚不能在卡片内浏览所有已配置平台；部分提供方的余额或额度扣减反馈字段仍待补齐。

### 安装、兼容与校验

- 主程序中打开“设置 → 桌宠”，下载并启用扩展；首次安装使用完整资源包，已有匹配资源的用户可只更新宿主。
- 附件：`TokenMeter-Pet-v0.2.0-x64.zip`、`TokenMeter-Pet-Host-v0.2.0-x64.zip`、`extension.json`、`SHA256SUMS.txt`。校验文件覆盖 ZIP 与清单；SHA256 不等同于独立发布签名。
- 本桌宠 Release 不占用仓库 Latest。原 VPet 角色与旧桌宠数据保持可用。
