更新类型：功能新增与界面优化（修订版）

本版本汇总 `v1.16.3` 之后的桌面显示调整，支持悬浮球与桌宠同时显示，并优化周额度圆环。配套桌宠继续使用 [`pet-v0.2.2`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.2)，主程序与桌宠仍独立下载和更新。

### 新增

- “设置 → 桌宠”新增“同时显示悬浮球”开关，默认关闭。开启后，桌宠运行时仍显示悬浮球，设置自动保存并立即生效，无需重启桌宠。
- 同时显示时，托盘可同步隐藏或恢复悬浮球与所有正在运行的桌宠；面板收起后按开关状态恢复显示。设置说明与提示支持现有五种界面语言。

### 优化

- 周额度改用淡底环和圆头渐变细弧，弱化水球外框与光晕，增加圆环和液面之间的留白，减少小尺寸悬浮球的拥挤感。
- 双额度模式稍微放大内部水球；周额度为零、满额、顺时针或逆时针显示，以及高峰计价提示继续保留。

### 验证

- Linux 无界面全量回归：1726 项通过、5 项 Windows 平台用例跳过，另有 174 项子测试通过；Ruff 全量检查、业务模块基本错误检查、Windows 目标 Pyright 和 Python 依赖审计通过。
- 回归覆盖开关默认值、保存与重载、即时切换、面板收起、多桌宠实例的托盘显隐，以及额度圆环和水球动画。
- Windows CI 覆盖全量 Python 测试、静态检查、依赖审计与 WPF 编译；发布工作流执行安装器打包、安装、覆盖安装数据保留和已安装程序启动自检。

### 安装、兼容与校验

- 附件：`TokenMeter-Setup-v1.16.4-x64.exe`、`SHA256SUMS.txt`。覆盖安装保留账户、用量、主题和桌宠配置。
- 桌宠继续使用 `pet-v0.2.2`，本次不重新发布桌宠扩展；最低兼容版本与通信协议不变。
- 主安装器不包含角色动画；SHA256 用于完整性校验，不等同于独立发布签名。
