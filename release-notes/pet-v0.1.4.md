更新类型：功能优化、Bug 修复

本版本汇总 `pet-v0.1.3` 之后的桌宠变更，让额度气泡和独立额度窗口跟随主程序主题。最低兼容主程序仍为 `1.14.0-beta.1`，平台为 Windows x64，通信协议保持 `1`。

### 优化与修复

- 同步额度气泡和独立额度窗口的明暗底色、正文、辅助文字、边框与按钮配色。
- 低额度文字和状态提示使用主程序警告色；恢复正常额度后回到当前主题文字与边框色。
- 旧主程序缺少新增可选主题字段时保留原有外观；仅接受 `#RRGGBB` 颜色，非法颜色保留之前配色，避免异常主题中断宿主。
- 保持已有贴边、额度展示、动画、提醒及独立更新行为。

### 验证

- 桌宠 .NET 依赖审计及 Release 构建通过，0 个警告、0 个错误。
- 扩展安装、打包、更新及主题桥接测试包含在主程序发布前回归中；新增宿主检查覆盖明暗底色、低额度警告和非法颜色回退。
- GitHub Actions 将再次执行桌宠安装更新回归并构建两个独立 ZIP；真实桌面拖拽与所有交互时序未在本次完整验收。

### 安装、兼容与校验

- 在“设置 → 桌宠”检查并升级；主程序 `v1.15.0` 配合本扩展可同步完整明暗主题。旧主程序继续使用兼容字段，不要求强制升级。
- 附件：`TokenMeter-Pet-v0.1.4-x64.zip`、`TokenMeter-Pet-Host-v0.1.4-x64.zip`、`extension.json`、`SHA256SUMS.txt`。已有完整扩展可复用动画资源并只更新宿主；首次安装使用完整包。
- 校验文件覆盖两个 ZIP 与清单；SHA256 不等同于独立发布签名。本 Release 不占用主程序 Latest。
