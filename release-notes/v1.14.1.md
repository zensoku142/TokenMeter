更新类型：功能新增、功能优化与文档更新

本版本在 `v1.14.0` 基础上补充已安装桌宠的自动更新提醒。更新能力位于主程序，桌宠扩展仍为 `pet-v0.1.0`，无需重新下载未变化的桌宠资源。

### 从 v1.13.2 及更早版本升级

可直接安装本版本，无需先安装 `v1.14.0`。旧版客户端的更新弹窗只显示目标版本的正文，因此在此补充中间版本的重要变化；已经使用 `v1.14.0` 的用户可略过本节。

- `v1.14.0` 新增可选 VPet 桌宠与独立扩展管理，支持下载、启用、更新和卸载；配套桌宠支持额度气泡、生活提醒和自主活动，主安装包仍不捆绑桌宠资源。
- 同一平台的不同账号分别保存用量、账单和分时历史，切换账号不再混用缓存。旧历史首次升级时归入当前账号，建议升级前备份应用数据目录并确认当前登录账号。
- 修复旧凭据清除、历史费用统计、Codex 本地日志统计和 Token 活动热力图分档问题；加强更新文件、压缩路径与桌宠版本兼容性校验。
- 平台请求与自定义接口要求有效的 HTTPS；原有 HTTP 自定义地址需要调整。源码用户如使用已移除的旧兼容导入入口，也需按项目结构说明调整。
- 优化深浅主题主色同步、Codex 水球动画和多平台历史采集性能，修复安装包 ICU DLL 冲突，并更新产品截图与第三方授权说明。

完整内容见 [v1.14.0 更新说明](https://github.com/zensoku142/TokenMeter/releases/tag/v1.14.0)；更早版本见 [全部更新记录](https://github.com/zensoku142/TokenMeter/releases)。本版本自身的桌宠自动更新提醒见下文。

### 新增

- “启动后自动检查”同时检查已安装的桌宠扩展，即使暂时关闭桌宠也能发现兼容新版；未安装桌宠时不检查、不下载。
- 发现桌宠新版后弹出确认提示，确认后直接打开“设置 → 桌宠”，复用现有下载进度、取消、校验和更新流程。同一版本在本次运行内只自动提示一次，暂不更新会在下次启动时再次提醒。
- 主程序“检查更新”也会检查已安装桌宠；保留桌宠页原有的手动检查入口，自动检查失败时不弹出错误打扰使用。

### 优化

- 主程序更新优先完成，重启后再按新主程序的兼容范围检查桌宠；旧桌宠暂不兼容时仍能发现可用更新。
- 主程序下载与桌宠安装、更新、卸载互相避让，防止安装器退出主程序时与扩展替换交叉执行；避免主程序与桌宠的自动提示嵌套弹出。
- 桌宠更新只暂停宿主，沿用失败回滚和偏好保留逻辑，不改变桌宠启用状态、账户、主题和面板设置；退出时取消并等待后台检查结束。
- 同步五种语言的设置提示和 README 当前版本，补充桌宠自动检查与更新说明。

### 安装、升级与校验

- 下载 `TokenMeter-Setup-v1.14.1-x64.exe` 安装或覆盖升级；同页 `SHA256SUMS.txt` 用于校验完整性。SHA256 不等同于独立发布签名。
- 需要升级主程序至本版本才能使用桌宠自动更新提醒，并保持“启动后自动检查”开启；桌宠新版仍需确认后才会下载安装。
- 本次只发布主程序，不创建新的桌宠版本。已有 `pet-v0.1.0` 扩展继续使用，未安装桌宠的用户不受影响。
