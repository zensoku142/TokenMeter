更新类型：Bug 修复与性能优化

本版本优化萝莉斯、鲸鱼娘和小龙娘的启动与动画加载，并独立记忆角色尺寸。桌宠扩展独立发布，不占用仓库 Latest。最低兼容主程序仍为 `1.17.0`，平台 Windows x64，通信协议保持 `1`。

### 优化与修复

- 优先准备常驻和交互动画，其他自主动作后台逐个预热；尚未就绪的动作按需准备，减少启动和切换角色的等待。
- 相同动画的预热与点播共用准备任务，避免重复解码；动画缓存完整写入后再发布，防止退出中断留下残缺缓存。
- 修复异步准备期间隐藏、拖动、切换角色或重新点播后，过期动作重新接管显示的问题，并保留自主动作序列衔接。
- 各模型分别保存尺寸，切换或重启后恢复；兼容旧布局的通用尺寸，小龙娘继续支持 80–320，其余角色保持 160–320。
- 主程序 `v1.17.1` 同步修正桌宠低额度提醒的自定义阈值和静默时段处理。

### 验证

- Windows 三角色真实 WPF 回归 26 项全部通过，覆盖独立尺寸保存、重启与角色切换、按需动作取消和播放、自主序列衔接、拖动与屏幕边界物理交互。
- 动画缓存、扩展安装和更新相关测试包含在主程序回归中：1964 项测试、178 项子测试通过，5 项跳过。
- 桌宠宿主 Release 编译通过，0 警告、0 错误；NuGet 依赖审计通过。
- 桌宠发布流水线执行扩展安装、打包和更新测试，构建完整包、宿主包和分角色包并生成校验文件。
