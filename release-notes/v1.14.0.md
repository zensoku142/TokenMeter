更新类型：功能新增、Bug 修复、功能优化、重构与文档更新（正式版）

本版本汇总自上一个正式版 `v1.13.2` 以来的全部更新，包含 `v1.14.0-beta.1` 体验版及其后的修复与优化，替代主程序 Latest。配套可选桌宠正式扩展为 `pet-v0.1.0`，主程序和桌宠分别编号、打包与更新。

### 新增

- 新增独立的“设置 → 桌宠”页，支持按需下载、取消、启用、检查更新、更新和卸载 VPet 精简桌宠，常驻显示版本、安装状态和上游来源链接，并提供五语设置文案。
- 桌宠加载成功后替代悬浮球，可打开原用量面板和设置；关闭、卸载或异常退出时恢复悬浮球，主程序退出时同步关闭宿主。主安装包不包含桌宠资源或 .NET 运行时，不启用时不会自动下载。
- 配套桌宠支持触摸、提起、拖动、缩放、贴边、额度水位气泡和自主活动；正式扩展新增悬停/随机额度展示、可独立开启的喝水与休息提醒，以及更完整的待机动作。详见 [桌宠正式版说明](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.1.0)。

### 修复

- 配套桌宠修复启用后仍出现在 Windows Alt+Tab 窗口切换列表的问题，常驻桌宠与额度气泡不再占用独立切换项，保留原有鼠标交互和主面板入口。
- 修复同一平台切换账号后复用旧账号内存快照、历史账单与分时数据的问题；按匿名账号指纹隔离缓存，并丢弃请求期间账号已变化的返回结果，防止旧数据写入新账号。
- 清空凭据时同时删除 TokenMeter、TokenSpider 与 TokenScope 的兼容存储项，避免旧凭据在下次启动时重新出现；凭据后端不可用时如实报告清除失败。
- 平台凭据请求要求 HTTPS，禁止重定向降级到明文连接；官方地址识别同时核对当前平台及端口。更新元数据、校验清单和文件下载增加实际大小上限，失败后清理未完成下载。
- 修复历史账单更新后本地累计费用未重算、旧日分时数据读取失败被误显示为空，以及历史初始化失败后继续使用错误账号数据的问题。
- 修复 Codex 本机会话日志末尾未写完、UTF-8 分段及同路径文件替换时的统计错误，跳过超长无关行，避免无界内存分配。
- 修复 Token 活动热力图分档失真：按年度峰值的实际比例划分五档，非零用量至少显示第一档，不再将普通用量拉伸到深色。
- 桌宠安装与更新校验 SHA256、平台、协议和版本范围，阻止危险压缩路径及版本降级；取消、替换失败或进程中断时保留或恢复旧包，对 Windows 短暂文件占用进行有限重试。
- 排除打包环境中的冲突 ICU DLL，覆盖安装时清理旧包遗留文件；启动自检以真实 Qt 渲染及退出码判定成功。同步主程序、更新器和安装器的正式版本信息。

### 优化

- 深浅模式默认同步主题主色，也可关闭同步后分别设置；各模式透明度保持独立，修复切换或重启后的主色不一致。
- 优化 Codex 悬浮球的液体动态、拖动惯性、面积与额度水位一致性，并缓存未变化的面积计算；本批次曾回退旧方案，正式版包含后续重新实现的液体效果。
- Codex 官方统计已有当天数据时不再扫描本机会话目录；需要估算时只处理当天活跃文件，仍只补近 7 天图的当天值，不替代官方热力图与底部统计。
- NayutoAI 请求明细改为持久化分页同步，支持断点续传、重叠去重、每日校对与旧缓存清理，减少重复抓取和长时间阻塞。
- 分时历史仅常驻当天数据，查看旧日期时按需读取；同一天的 Token、费用与模型明细共用数据库连接和读事务，减少重复开库与内存占用。
- 桌宠只通过本机父子进程管道接收展示字段，不接收 API Key、Cookie 或登录信息；动画缓存与资源加载进一步优化，保留来源和依赖授权文件。

### 重构与文档

- README 更换为当前源码的真实产品截图，补齐演示数据说明、VPet 来源与素材授权；精简并同步五种语言的使用说明与当前版本。
- 更新 setuptools、Ruff 依赖要求，补充运行模块检查、Python/NuGet 依赖审计、桌宠独立构建和发布校验；清理测试窗口与定时器，并隔离语言状态，避免英文 CI 中的测试相互影响。

### 安装、升级与校验

- 下载 `TokenMeter-Setup-v1.14.0-x64.exe` 安装或覆盖升级；同页 `SHA256SUMS.txt` 用于校验完整性。SHA256 不等同于独立发布签名。
- 桌宠按需通过“设置 → 桌宠”下载并手动启用；已安装体验版扩展的用户可单独检查更新至 `pet-v0.1.0`，无需卸载主程序。
- 旧历史没有账号标识，首次升级时归入该平台当前凭据对应的账号；后续换号保留旧记录但不混用。建议升级前备份应用数据目录，并确认当前登录账号。
- 自定义接口地址必须使用有效的 HTTPS；旧 HTTP 地址需修改后使用。自行导入已移除兼容入口的源码脚本需按 [项目结构说明](https://github.com/zensoku142/TokenMeter/blob/v1.14.0/docs/PROJECT_STRUCTURE.md) 调整导入路径。
- 桌宠为 Windows x64 可选扩展，原生右键菜单目前仍为中文；默认角色与动画适用上游单独授权。
