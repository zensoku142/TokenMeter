更新类型：Bug 修复与性能优化（修订版）

本版本汇总 `v1.16.2` 之后的本机统计、Codex 日志解析和扩展包校验修复。桌宠扩展保持 `0.2.2`，主程序与桌宠仍独立下载和更新。

### 修复与优化

- 本机统计在日志或数据库读取失败后清理失效汇总，恢复访问后重新读取；日志已清空时同步清空旧快照，读取异常数变化也会更新缓存。
- 异常时间戳和过深 JSON 只影响当前记录，不再中断整轮扫描。ZCode 读取后及时关闭数据库连接；连续扫描时，上一轮快照不会覆盖新结果。
- Codex 平台用量解析支持 JSON 空格和字段重排，拒绝非整数或负数 Token，避免坏日期和坏计数污染后续增量；混合有时区、无时区的任务时间可正常计算时长。
- 项目筛选后立即切换页面，返回时总数、表格与导出范围保持一致。日期边界和筛选关键词不再逐条重复计算；20 万条记录的内存基准中，筛选约提速 2.74 倍，每日模型聚合约提速 1.92 倍，输出一致。
- 桌宠扩展包按目标 Windows 平台校验保留文件名，避免在其他系统检查时放行无效名称。

### 验证

- Linux 无界面完整回归：1720 项通过、5 项 Windows 平台用例跳过，另有 172 项子测试通过；Ruff、Windows 目标 Pyright、依赖审计和真实 Qt 组件渲染自检通过。
- Windows CI 覆盖全量 Python 测试、静态检查、依赖审计与 WPF 编译；发布工作流继续执行打包、安装、覆盖安装数据保留和已安装程序启动自检。
- 分批复现、回归与性能对照见 [开发验证记录](https://github.com/zensoku142/TokenMeter/blob/v1.16.3/release-notes/v1.16.3-validation.md)。性能数字仅代表内存数据处理，不代表完整磁盘扫描或界面耗时。
