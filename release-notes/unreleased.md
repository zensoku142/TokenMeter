# 未发布改进记录

更新类型：Bug 修复、性能优化、测试改进。

基线：`0745161`（主程序 v1.16.2）。本次为开发提交，保持公开版本号不变；正式发布前仍需 Windows CI 和桌面验证。

## 第一批：扩展包路径校验

- 桌宠扩展始终按 Windows 规则拒绝保留文件名，避免在 Linux 校验时放行 `CON`、`NUL`、`COM1.log` 等名称。
- 增加嵌套目录、带扩展名、大小写及上标数字设备名的回归用例。
- Codex 目录选择测试改用当前系统的临时目录，继续验证从 `auth.json` 转为目录、只读输入、浏览选择、保存和恢复默认值。

验证：`tests/test_pet_extension.py` 与目录选择用例共 **104 项通过**。重复 ZIP 条目用例产生一条预期警告。

## 第二批：本机统计可靠性与性能

- 日志读取或数据库读取失败后，立即使已移除文件的汇总缓存失效，避免继续显示旧用量；恢复访问后重新读取。
- ZCode 数据库读取成功或失败后都立即关闭 SQLite 连接，不依赖垃圾回收释放句柄。
- 单条 ZCode 记录的时间戳超出系统可表示范围时，只跳过该记录并计入读取异常，保留其余有效统计。
- 日期边界和项目关键词在每次筛选时只计算一次，减少大量记录下切换筛选和图表的重复工作。

验证：新增的 **5 个回归用例在修复前均失败**；修复后本机统计和 Excel 导出相关测试共 **29 项通过**。

### 性能对照

同一 Linux / Python 3.12.14 环境，对比基线 `0745161` 与本次实现。使用 200,000 条内存中的 `LocalUsage`：同一 Codex 平台、项目名 `Example-Project`，12 个模型，日期均匀分布于 2026-09-01 至 2026-09-28，每条总量为 110 Token。筛选条件为截至 2026-09-30 的 30 天及关键词 `PROJECT`；每日模型聚合范围为 2026-09-01 至 2026-09-30。

先检查新旧输出相等，再交替执行新旧实现各 7 次，报告单次耗时的中位数：

| 操作 | 修改前 | 修改后 | 提速 |
| --- | ---: | ---: | ---: |
| `filter_usage` | 67.760 ms | 24.705 ms | 2.74 倍 |
| `daily_model_series` | 151.179 ms | 78.692 ms | 1.92 倍 |

这是内存数据处理基准，不代表包含磁盘扫描和 UI 渲染的完整操作耗时。

## 第三批：异常日志隔离

- Codex 和 Claude 单条日志的时区换算溢出、系统日期转换错误或 JSON 递归过深时，跳过该记录并计入读取异常，不再中断整轮本机统计。
- Codex 在日期校验通过后才更新累计基数，避免坏记录消耗后续有效用量的差分。
- 新增两个平台的日期上下界和深层 JSON 回归用例；其中深层 JSON 用例使用 10,000 层嵌套，已确认在基线实现中触发扫描异常。

验证：本机统计与 Excel 导出 **35 项通过**；Ruff 和差异空白检查通过。

## 第四批：统计快照一致性

- 首次扫描即使没有日志，也会用空结果替换该范围的旧磁盘快照，避免下次打开继续短暂显示已删除的统计。
- 仅读取异常数改变时更新快照，同时复用未变化的统计行，避免图表重新聚合。
- 快照保存完成或失败后才发送扫描完成信号，避免用户立即重扫时被上一轮的迟到写入覆盖。保存失败仍交付有效内存结果。

验证：增加空结果覆盖、异常数变化、连续扫描和存储失败回归；连续扫描用例在旧实现中将已更新的 360 Token 快照覆盖回 180 Token。相关测试 **39 项通过**，Ruff 和差异空白检查通过。

## 第五批：项目筛选切页一致性

- 输入项目筛选后立即离开统计页时，先应用尚未触发的防抖筛选，再停止定时器，避免快速返回后页面总数、表格和导出范围不一致。

验证：新增快速隐藏/重新显示的 UI 回归用例；原实现保留 30 Token 的旧总数，修复后与筛选结果一致显示 10 Token。本机统计与 Excel 导出 **40 项通过**。

## 第六批：Codex 平台本地用量解析

- 从已解析的 JSON 中读取时间戳，支持字段重排和普通 JSON 空格，不再依赖固定字符串前缀。
- 只接受非负整数 Token 计数；布尔值、浮点数、数字字符串、空值和无穷大不再改变累计基数。
- 日期无效、时区转换溢出或 JSON 递归过深时只跳过当前记录，保留后续用量增量。
- 任务边界时间统一为有时区的本地时间，避免混合有时区/无时区记录导致比较异常。
- 无关日志行不再提前执行时间戳匹配和日期解析。

验证：新增 15 个参数化解析场景，旧实现 **14 失败、1 通过**；修复后审计回归与 Provider 测试 **85 项通过、22 个子测试通过**。Ruff、运行时基本错误检查与 Windows 目标 Pyright 均通过。
