更新类型：功能新增、Bug 修复与功能优化（修订版）

本版本汇总 `v1.16.0` 之后的桌宠安装与多开体验，替代主程序 Latest。配套桌宠扩展为 [`pet-v0.2.1`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.1)；主程序和扩展继续独立安装、更新。

### 新增

- “设置 → 桌宠”可只下载所选角色；安装后可单独添加或删除 VPet 默认角色、鲸鱼娘。删除最后一个角色时卸载共用宿主；旧桌宠版本仍可使用完整包安装。
- 可分别设置 VPet 和鲸鱼娘的额外实例数量，同一角色也能多开。每份实例独立保存窗口位置和动画缓存，用量、托盘显隐、更新暂停与退出由主程序统一管理；默认额外数量为零，保持原有单开行为。
- 每只桌宠可在右键“显示来源”中独立选择主程序当前平台、已配置平台的默认账户或账户档案。绑定来源会独立刷新；档案编辑、删除后旧账户快照立即失效。

### 修复与优化

- 旧版桌宠宿主会同时读取两个角色资源；设置页要求先更新扩展，再允许单独删除角色，避免旧宿主启动失败。
- 主安装器排除构建目录中残留的桌宠资源，仍保留设置页需要的角色缩略图；覆盖安装不删除用户数据。

### 验证

- 本地全量 Python 回归 1685 项通过、4 项跳过，另有 172 项子测试通过；Ruff 和 Python 依赖审计通过。
- 本地 PyInstaller onedir 构建与真实 Qt 启动自检通过；Inno Setup 编译出 `TokenMeter-Setup-v1.16.1-x64.exe` 并生成 SHA256 校验文件。桌宠 WPF 宿主 Release 构建通过，0 警告、0 错误；GitHub Actions 将再次运行全量测试、构建和安装覆盖验证。

### 安装、兼容与校验

- 主程序附件为 `TokenMeter-Setup-v1.16.1-x64.exe` 和 `SHA256SUMS.txt`。安装主程序后，在“设置 → 桌宠”下载对应角色；分角色下载与多开需配套桌宠 `0.2.1`。
- 扩展通信协议仍为 `1`。旧版桌宠可继续安装使用，更新到配套扩展后才显示单角色管理入口。SHA256 提供文件完整性校验，不等同于独立发布签名。
