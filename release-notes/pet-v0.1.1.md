更新类型：Bug 修复、功能优化与文档更新

本版本修复生活提醒可能长期不触发的问题，并提升小尺寸桌宠的提示文字可读性。建议配合主程序 `1.14.2` 使用；最低兼容主程序仍为 `1.14.0-beta.1`，平台为 Windows x64，通信协议保持 `1`。

### 修复

- 修复从桌宠打开用量面板时，主程序重复发送“显示桌宠”命令，导致喝水、休息和随机额度倒计时被重新开始的问题；频繁查看用量不再让生活提醒持续延期。
- 保留真正隐藏、系统休眠后的重新计时语义，恢复时不补发积压提醒；重复的同状态显示命令不再中断当前动作或提醒。

### 优化

- 小尺寸桌宠的文字对话框会补偿角色画布缩放，实际提示字号至少为 `14`，自动换行且不改变角色大小；`220`、`320` 尺寸继续保留原有可读比例。
- 提醒仍只显示正文、不显示角色称呼；喝水与休息同时到期时合并显示，继续支持自动淡出和双击关闭。
- 补充真实 `DispatcherTimer`、重复打开面板及 `160` / `220` / `320` 三种尺寸的布局检查，避免手动推进时间掩盖计时器生命周期问题。

### 验证

- 桌宠宿主编译通过，真实宿主加载 `318` 组动画；`285` 项原生交互与布局检查全部通过，动画加载错误为空。
- 重复打开面板的四项回归检查在旧逻辑下全部失败，修复后全部通过；真实计时器能够按顺序触发喝水与休息提醒。
- `14` 项 Qt 桌宠桥接测试通过；真实 QProcess 管道验证通过，桌宠加载完成、面板切换、显隐和退出均正常。
- 扩展安装、更新、打包与更新客户端相关测试 `139` 项通过；发布工作流会再次构建独立 ZIP、版本清单和 SHA256 校验文件。
- .NET 构建未引入新依赖；通过 NuGet 官方源检查直接和间接依赖，未发现已知漏洞。

### 安装、兼容与校验

- 主程序 `1.14.1` 或更新版本可在启动检查时提示已安装桌宠更新；也可进入“设置 → 桌宠”手动检查并升级。更新期间暂停桌宠，完成后按原开关状态恢复，不影响账户、用量、主题或主程序面板。
- 附件：`TokenMeter-Pet-v0.1.1-x64.zip`、`extension.json`、`SHA256SUMS.txt`。校验文件覆盖 ZIP 与版本清单；SHA256 不等同于独立发布签名。
- 通信协议和最低兼容主程序版本未变，`pet-v0.1.0` 用户可直接升级；稳定主程序只选择稳定桌宠扩展。
