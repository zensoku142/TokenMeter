更新类型：功能优化与 Bug 修复（修订版）

本版本优化 Codex 和 NayutoAI 的 Token 速度视图，并修复部分主题下的页签文字颜色。配套桌宠继续使用 [`pet-v0.2.2`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.2)，主程序与桌宠仍独立下载和更新。

### 优化

- 主程序支持识别同版本安装包的热补丁：安装新版后，同一版本的后续修订可通过自动或手动检查发现；跳过操作只针对当次安装包。
- 发布工作流支持手动重发当前版本，并在构建、安装验证和校验通过后同步标签及 Release 附件。
- 速度 K 线一次只展示一个模型，点击图例切换；默认选择输出量最多的模型，刷新时保留有效的选择，原模型无有效请求时自动回退。
- K 线、MA5、导航和悬停提示均使用当前模型的数据；切换模型后定位到其最近时段，避免不同模型的速度混合。

### 修复

- 修复软件更新、下载进度和桌宠更新提示被置顶面板或看板遮挡后无法操作的问题；下载期间避免重复弹出自动更新提示。
- 修复部分自定义蓝色主题或明暗主题颜色联动下，选中页签文字显示为黑色的问题；极浅背景使用深色文字，保证文字可辨认。

### 安装、兼容与校验

- 已安装原版 v1.16.7 的用户需要下载本页安装包并覆盖安装；同版本更新不会触发自动升级。
- 如旧版客户端使用缓存下载失败，请在设置中手动检查更新后重试。
- 附件：`TokenMeter-Setup-v1.16.7-x64.exe`、`SHA256SUMS.txt`。覆盖安装保留账户、用量、主题和桌宠配置。

- 主安装器不包含角色动画；SHA256 用于完整性校验，不等同于独立发布签名。
