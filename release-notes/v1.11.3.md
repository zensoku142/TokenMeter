更新类型：功能优化

### 优化

- Codex 订阅摘要不再显示账户邮箱，避免在桌面面板暴露账号信息。
- 新增“套餐到期”卡片，读取当前订阅的有效截止日期，并以本地日期展示月份、日期和年份。
- 套餐截止日期采用独立容错和 6 小时缓存；订阅元数据请求失败时仅显示 `--`，不影响原有额度、趋势和本地 Token 统计。

### 兼容

- 保持 Codex CLI OAuth 登录、额度查询、Provider 返回结构及现有缓存降级行为兼容。
- 不改变 DeepSeek、Xiaomi MiMo、SQLite 历史数据、配置字段、凭据存储和自动更新协议。

### 验证

- 完整自动化测试：`280 passed, 9 subtests passed`。
- 已使用真实 Codex 登录状态完成只读订阅截止日期获取与本地界面运行验证。
- Python 编译检查与 `git diff --check` 通过。

### 安装与校验

- 从本 Release 下载 `TokenMeter-Setup-v1.11.3-x64.exe`。
- 可使用同页 `SHA256SUMS.txt` 校验安装包完整性；SHA256 不等同于独立发布签名。
