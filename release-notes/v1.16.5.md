更新类型：功能新增与 Bug 修复（修订版）

本版本补充 Codex 本机会话日志的今日分时统计，并修复订阅面板分时控件重叠。配套桌宠继续使用 [`pet-v0.2.2`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.2)，主程序与桌宠仍独立下载和更新。

### 新增

- Codex 面板支持切换“年度活动 / 今日分时”。按会话日志的记录时间聚合缓存命中、新增输入和输出 Token，显示模型提示，并复用现有分时间隔、图表样式和历史日期选择。
- 支持增量读取及归档记录去重；优先使用日志中的单次请求用量，避免把续聊继承的累计历史归入首个新请求。旧版统计快照继续可读。
- 分时来源明确标记为“本机日志”，按日志目录与本地时区隔离缓存。仅统计本机可读取记录，账号归属未知，不代表账号全部用量、订阅额度或实际账单；未提供的实际费用保持未知。

### 修复

- 修复 Codex 今日分时头部的日期、切换按钮、图例与汇总文字重叠。日期和视图切换保留在第一行，日志来源、图例、汇总和额度明细移到第二行；窄窗口收起汇总文字。
- 切换分时日期、刷新和切回年度活动时保留订阅额度卡片；官方年度统计与本机分时记录保持各自的数据来源。
- 保留 Claude 等订阅平台未提供 Token 明细时的提示，避免共用布局刷新覆盖来源说明。
- 同步主程序、更新器和安装器的 Windows 版本信息，保持安装包版本标识一致。
- 将开发与打包环境的 Pillow 更新到已修复已知漏洞的版本范围，避免旧版本上限阻断发布依赖审计。
