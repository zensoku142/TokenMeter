更新类型：功能新增与优化（修订版）

本版本增加 Codex 和 NayutoAI 的 Token 输出速度视图，并优化年度活动图的色阶。配套桌宠继续使用 [`pet-v0.2.2`](https://github.com/zensoku142/TokenMeter/releases/tag/pet-v0.2.2)，主程序与桌宠仍独立下载和更新。

### 新增

- Codex 和 NayutoAI 面板增加“Token 速度”，按日期、模型和时间展示最近速度、均速、峰值及 K 线趋势；支持模型筛选、缩放、导航和悬停查看。
- 速度按有效请求的输出 Token 除以请求耗时估算，包含首字等待；未完成、输出不足 200 Token、耗时不足 1 秒或超过 1 小时的请求不计速。首字时间仅在记录提供有效信息时显示。
- Codex 使用所选目录的本机会话日志推算请求耗时，并处理增量扫描、工具等待和旧快照兼容；NayutoAI 使用请求记录中提供的耗时。缺少有效计时的数据不会被当作零速度。

### 优化

- 年度活动图根据非零用量分布限制色阶上限，减少异常峰值对普通日期颜色的影响，保留最高档显示。
- 优化速度图和分时图的悬停、图例与窄窗口布局，减少鼠标移动时重复计算；多模型并发、主题及语言切换保持可用。
- 日志目录切换时清除旧目录的速度快照，同一目录读取失败时保留缓存并明确标记。

- Qt 离屏测试覆盖 Codex / NayutoAI 在 640 / 820 像素、中文 / 英文下的速度页切换、刷新及主题变化；年度热力图覆盖深色和浅色主题。
