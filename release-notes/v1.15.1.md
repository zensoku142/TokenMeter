更新类型：Bug 修复

本版本修复蓝鲸女仆角色包在 GitHub Actions 构建后与主程序内置校验值不一致，导致下载完成后被客户端拒绝的问题。

### 修复

- 将人物形象目录中的 SHA-256 与 GitHub Release 实际上传附件保持一致。
- 同步附件真实大小，下载进度与安装前校验使用同一发布产物数据。

### 验证

- 已核对 `pet-character-blue-whale-maid-v0.0.1` Release 附件 API 返回的 SHA-256 与大小。
- 角色目录、下载校验、安装与卸载相关测试通过。
- Ruff、Pyright 与 Git 差异检查通过。

### 安装、升级与校验

- `v1.15.0` 用户应升级到本版本后再下载蓝鲸女仆人物形象。
- 下载 `TokenMeter-Setup-v1.15.1-x64.exe` 安装或覆盖升级；`SHA256SUMS.txt` 用于校验。
- 完整差异：[v1.15.0 → v1.15.1](https://github.com/zensoku142/TokenMeter/compare/v1.15.0...v1.15.1)。
