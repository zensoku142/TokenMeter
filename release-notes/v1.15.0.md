更新类型：功能新增、Bug 修复与功能优化

本版本新增可下载人物形象管理，并配套升级桌宠宿主与资源校验。桌宠程序、人物资源和用户偏好继续彼此独立。

### 新增

- “设置 → 桌宠”新增人物形象选择器，支持下载、切换和卸载外部角色包。
- 当前角色被卸载或资源损坏时自动回退内置默认角色，不影响桌宠布局、提醒、账户和用量数据。
- 新增独立角色包清单、SHA-256 下载校验、安全解压和原子替换流程。
- 内置蓝鲸女仆 `0.0.1` 下载目录，角色包单独发布，不增加主安装包体积。

### 修复与优化

- 切换人物形象时只重启本实例创建的桌宠宿主，不结束其他 VPet 进程。
- 外部角色沿用同一动画缓存目录，缓存指纹会在资源替换后自动失效。
- 补齐简体中文、繁体中文、英语、日语和韩语界面文案。

### 验证

- Python 3.12 全量回归：711 项通过，3 项跳过，28 项子测试通过。
- 角色管理、下载校验、危险 ZIP 路径、切换和卸载回退专项测试 16 项通过。
- Ruff、Pyright、Git 差异检查和 .NET Release 构建通过。
- 真实外部角色包加载 318 个动画段，动作面板覆盖 16 个 Move 入口。

### 安装、升级与校验

- 下载 `TokenMeter-Setup-v1.15.0-x64.exe` 安装或覆盖升级；`SHA256SUMS.txt` 用于校验。
- 人物形象功能建议同时升级桌宠扩展至 `pet-v0.2.0`。
