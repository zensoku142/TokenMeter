更新类型：功能新增、Bug 修复、功能优化、文档更新

本次发布汇总 `v1.14.2` 以来的完整主程序开发批次：从五平台用量面板扩展为 15 个独立平台入口，增加多平台总览、多账户、本机统计、Excel 导出、额度预测与提醒、双平台置顶看板。现有默认连接、CLI 登录、用户数据目录及安装升级方式保持兼容。

### 新增

- 新增 Claude Code、GitHub Copilot、GLM / Z.ai、Kimi Coding、MiniMax Token Plan、Gemini CLI、ElevenLabs、Antigravity CLI、OpenRouter 和 Moonshot / Kimi API 入口。Claude 支持只读本机 OAuth 或显式状态栏快照；Antigravity 使用用户配置的官方状态栏快照，不调用模型生成接口。
- “额度明细”展示平台实际提供的全部额度窗口、账户指标、重置时间与数据来源。订阅额度、API 余额、密钥预算分开呈现，不合并币种或推算未提供的账单数据。
- 多平台总览显示独立额度、余额、最后成功时间和连接恢复入口；页面可见时按分钟逐个更新，复用采集退避并跳过刚刷新过的平台。
- “设置 → 多账户”保存同一平台的独立连接，支持添加、编辑、删除和监控。凭据进入 Windows 凭据管理器，历史缓存按档案和实际账号隔离，迟到响应不能覆盖已修改或删除的档案。
- 本机统计自动读取 Codex（含归档）和 Claude 日志，先显示缓存再增量更新。支持日期与项目筛选、Top 排行、每日模型比较、图表/表格、图例筛选、缩放、横移和分项提示；后台导出 Excel 汇总、明细和口径说明。
- 可选低额度提醒、恢复提醒、额度消耗预测和通知静默时段；跨重启保留提醒状态，静默时段支持跨午夜。预测需同周期至少 10 分钟有效样本，恢复提醒需先启用低额度提醒，并以实际刷新确认恢复。
- 独立置顶双平台看板复用总览和刷新队列，记住两个已配置平台的选择，优先展示最紧张的额度窗口，并提供详情入口。

### 修复

- 修复部分平台异常数值、畸形用量数组、账号切换后的缓存恢复和币种显示；加固平台错误文案的隐私处理。
- 修复历史费用统计口径与缓存边界，避免重复刷新和旧账号数据干扰当前展示。
- 修复悬浮球收到相同读数后水面动画停止、设置透明度拖动卡顿及实时预览问题；修复数字框箭头和百分比文字截断。
- 加固平台删除、设置弹窗、刷新队列关闭和异步生命周期处理；移除平台只清除本应用连接，保留 CLI 登录及历史记录。

### 优化

- 使用随包分发的离线品牌 SVG，统一顶部导航、纯图标快捷入口、平台搜索与收藏；支持点击星形或 `Ctrl+D` 收藏。
- 统一 Token 显示单位、面板圆角、设置页签顺序和交互图表导航；图例保持单行并支持横向浏览，每日图表按可见模型隐藏空日期。
- 总览更新复用卡片和样式，减少重复整页刷新；自动采集在限流或网络失败后退避，手动刷新可主动重试。
- 桌宠桥接同步明暗主题、额度与提示配色；扩展下载支持独立宿主更新，已有动画资源无需重复下载。桌宠自身的主题改动在独立 `pet-v0.1.4` 发布。
- 新增模块纳入 Ruff、运行模块基本错误检查、Pyright 和打包配置；测试隔离真实 Windows 凭据、CLI 登录发现和本地历史数据。
- 更新五种语言 README、GitHub Pages 功能与版本信息、真实组件截图和平台配置指南；官网支持五种语言、明暗主题及对应语言截图。更新记录统一保存在 Release 文案中。

### 安装、兼容与校验

- 下载 `TokenMeter-Setup-v1.15.0-x64.exe` 安装或覆盖升级，同页 `SHA256SUMS.txt` 校验完整性。SHA256 不等同于独立发布签名。
- 本机日志统计的账户归属未知，不代表订阅剩余额度或实际账单。可显式选择已可访问的 WSL 目录，不会启动 WSL。
- 各平台权限和数据范围不同：OpenRouter 展示密钥预算，Kimi API 与 Kimi Coding 使用独立凭据；Gemini 与 Copilot 的实验性接口及账号限制见 README 所链接的指南。缺失字段显示不可用。
- 主安装包不含桌宠；桌宠独立升级至 `pet-v0.1.4` 可使用完整主题同步，旧扩展仍可连接。桌宠此前已发布的 `pet-v0.1.1` 至 `pet-v0.1.3` 包含生活提醒、贴边状态及启动修复，详见各自 Release。
