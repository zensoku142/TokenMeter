更新类型：Bug 修复与功能优化（修订版）

本版本汇总 `pet-v0.2.1` 之后的提醒、角色动画与右键交互修正，不占用仓库 Latest。请先升级主程序 [`v1.16.2`](https://github.com/zensoku142/TokenMeter/releases/tag/v1.16.2)；最低兼容主程序为 `1.16.2`，平台 Windows x64，通信协议仍为 `1`。

### 修复

- 喝水和休息提醒不再被贴边状态阻止：到期后临时移入屏幕显示，结束后恢复原贴边位置；随机额度提示继续保持原有贴边限制。
- 鲸鱼娘全部 106 个动作与站立素材采用相同固定取景和脚底基线，消除动作开始时人物突然缩小、结束后恢复的比例跳变。自定义 WebM 使用相同规则，旧转码缓存自动失效。
- 修正鲸鱼娘模拟甩抛自检被真实鼠标事件中断的问题，继续通过真实物理计时器检查释放后的位移。

### 优化

- 右键菜单增加“再开一只桌宠”和“关闭这只桌宠”，分别请求主程序新增已安装角色或关闭当前实例；萝莉斯使用角色本名。
- 移除右键“放大桌宠 / 缩小桌宠”，保留 Ctrl 加鼠标滚轮调整大小。
- “额度气泡展示”增加可持久保存的关闭选项；重新勾选“显示额度气泡”可恢复展示。
- 扣款与额度减少的浮动提示延长至 4 秒，前三秒保持清晰、最后一秒淡出，上飘速度相应放慢。

### 验证

- 本地全量 Python 回归 1685 项通过、4 项跳过，另有 172 项子测试通过；Ruff 与依赖审计通过。真实待机动作的首帧与站立帧逐像素一致，106 个动作已重新转码。
- WPF 宿主 Release 编译通过，0 警告、0 错误；萝莉斯 291 项提醒、气泡和生命周期自检通过，鲸鱼娘 34 项动作、甩抛、自定义转码和余额卡片检查通过。
- GitHub Actions 再次执行扩展测试、完整包及分角色包构建，并生成附件校验文件。

### 安装、兼容与校验

- 附件：`TokenMeter-Pet-v0.2.2-x64.zip`、`TokenMeter-Pet-Host-v0.2.2-x64.zip`、`TokenMeter-Pet-vup-v0.2.2-x64.zip`、`TokenMeter-Pet-whale-v0.2.2-x64.zip`、`extension.json`、`SHA256SUMS.txt`。
- 新的实例菜单需要主程序 `1.16.2` 处理，因此本版提高最低兼容版本；旧主程序继续使用兼容的桌宠 `0.2.1`，升级主程序后再更新桌宠。
- 动作采用与站立素材相同的中央取景，超宽特效的边缘可能落在画布之外。自定义 WebM 仍需用户自行提供 FFmpeg，发布包不分发 FFmpeg 可执行文件。
- 更新保留桌宠偏好和账户数据；SHA256 提供附件完整性校验，不等同于独立发布签名。
