更新类型：功能新增与优化

本版本新增小龙娘角色，桌宠扩展独立发布且不占用仓库 Latest。请先升级主程序至 `v1.17.0`；最低兼容主程序为 `1.17.0`，平台 Windows x64，通信协议为 `1`。

### 新增

- 新增小龙娘角色，提供 35 段动画、自主活动、动作菜单和移动；支持额度气泡、显示来源、拖动缩放与多开。
- 支持单独下载和管理小龙娘角色资源；动画不包含 AI 对话或历史会话。

### 优化

- 改进鲸鱼娘及小龙娘的拖拽、甩抛与边界碰撞表现。
- 优化桌宠动画缓存和资源加载，调整桌宠宿主与角色管理。

### 验证

- Windows 本地针对性测试 218 项通过、1 项跳过；桌宠宿主 Release 编译通过，0 警告、0 错误。

- 发布流水线将执行桌宠扩展、打包和更新测试，构建完整包与分角色包并生成校验文件。

### 安装、兼容与校验

- 附件包括完整包、宿主包、萝莉斯、鲸鱼娘和小龙娘分角色包，以及 `extension.json`、`SHA256SUMS.txt`。
- 小龙娘角色管理需要主程序 `1.17.0`；旧版主程序可继续使用兼容的桌宠 `0.2.2`。更新保留桌宠偏好和账户数据。
- SHA256 用于完整性校验，不等同于独立发布签名。
