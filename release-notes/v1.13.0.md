更新类型：功能更新

### 新增

- 新增 Cursor 个人订阅数据源，读取本机 Cursor 数据并展示订阅额度与用量状态。
- 新增 NayutoAI 数据源，支持 Bearer 凭据、余额与消费统计、分时费用和按模型拆分的近 7 天 Token 用量。
- 新增后台数据源多选配置；默认只获取当前选择的数据源，仅对明确勾选且已配置的其他数据源执行后台定时获取。
- 新增 NayutoAI 模型用量视图与模型 Tooltip，切换数据源时分别保留各平台的图表状态。

### 优化

- 优化 Codex 额度重置时间的紧凑显示，并统一不同数据源的原生币种、额度和状态格式。
- 优化悬浮球滚轮缩放、贴边吸附与自动隐藏交互，降低空闲状态下的轮询与运行时内存占用。
- 更新多语言 README 的界面展示与当前版本信息，并补充 Cursor、NayutoAI 及界面设计实现文档。

### 修复

- 修复服务商凭据失效后重复弹出通知的问题；每个失效数据源只进入一次通知周期，保存配置后可重新验证。
- 修复后台刷新与数据源切换时的状态隔离，未勾选的数据源不会再被后台自动请求。
- 修复 NayutoAI 模型图表、分时数据和 Tooltip 在切换日期或数据源后的残留与闪烁问题。

### 兼容

- 新增配置默认使用空列表，升级后保持只刷新当前数据源，不改变已有凭据和历史数据结构。
- 保持 Codex、DeepSeek 与 Xiaomi MiMo 的登录、额度查询、缓存和自动更新协议兼容。

### 验证

- 完整自动化测试通过。
- 相关配置、后台刷新调度和 Qt 设置界面测试通过。
- `git diff --check` 通过；GitHub Actions 将再次执行测试、依赖审计、安装包构建、覆盖安装与启动冒烟验证。

### 安装与校验

- 从本 Release 下载 `TokenMeter-Setup-v1.13.0-x64.exe`。
- 可使用同页 `SHA256SUMS.txt` 校验安装包完整性；SHA256 不等同于独立发布签名。
